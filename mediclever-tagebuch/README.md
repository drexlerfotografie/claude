# MediClever Tagebuch

Android-App: Stimmungs- und Aktivitäten-Tagebuch, das jede Person selbst einrichtet.

- APK bauen: `./gradlew :app:assembleDebug`, Ergebnis unter `app/build/outputs/apk/debug/app-debug.apk`
- Alles prüfen: `./verify.sh`
- Firebase einrichten: `docs/firebase-einrichtung.md`
- Stand und offene Punkte: `docs/fortschritt.md`, Prüfliste: `docs/abnahme.md`
- Hinweise für die Arbeit mit Claude Code: `CLAUDE.md`
